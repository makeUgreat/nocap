# 명세 파싱

## 명세 항목 생성
- nocap은 명세 태그가 있는 리스트 항목마다 명세 항목 1개를 만듦 <!--@MD-001-->
- nocap은 명세 태그의 ID를 명세 항목의 ID로 씀 <!--@MD-002-->
- nocap은 명세 태그가 없는 리스트 항목으로 명세 항목을 만들지 않음 <!--@MD-003-->
- nocap은 문장 없이 명세 태그만 있는 리스트 항목도 명세 항목으로 만듦 <!--@MD-008-->

## 명세 태그 인식
- nocap은 주석 안쪽 앞뒤의 공백과 무관하게 같은 명세 태그로 인식함. 예: `<!--@ID-->`와 `<!-- @ID -->` <!--@MD-004-->
- nocap은 코드 블록과 인라인 코드 안의 명세 태그를 무시함 <!--@MD-005-->
- nocap은 리스트 항목 텍스트 맨 끝에 있는 명세 태그만 인식함 <!--@MD-006-->
- nocap은 리스트 항목의 첫 문단 끝을 그 항목의 맨 끝으로 봄. 하위 리스트와 둘째 이후 문단은 포함하지 않음 <!--@MD-007-->
