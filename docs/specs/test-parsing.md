# 테스트 파싱

## 테스트 항목 생성
- nocap은 테스트 태그가 붙은 테스트 호출마다 테스트 항목 1개를 만듦 <!--@TP-001-->
- nocap은 테스트 태그에 쓴 ID를 모두 쓴 순서대로 테스트 항목의 ID로 씀 <!--@TP-002-->
- nocap은 테스트 태그가 없는 테스트 호출로 테스트 항목을 만들지 않음 <!--@TP-003-->

## 테스트 호출 인식
- nocap은 `it`, `test`, `describe`, `suite` 호출만 테스트 호출로 인식함 <!--@TP-004-->
- nocap은 수식자가 붙은 호출도 테스트 호출로 인식함. 예: `it.skip()`, `test.each([...])()`, `describe.only()` <!--@TP-005-->

## 테스트 태그 인식
- nocap은 테스트 호출 바로 위 줄의 라인 주석만 테스트 태그로 인식함. 빈 줄이나 다른 주석이 사이에 있으면 인식하지 않음 <!--@TP-006-->
- nocap은 블록 주석과 테스트 호출과 같은 줄에 있는 주석을 테스트 태그로 인식하지 않음 <!--@TP-007-->
- nocap은 쉼표 앞뒤의 공백과 무관하게 같은 테스트 태그로 인식함. 예: `// @A-001,@A-002`와 `// @A-001, @A-002` <!--@TP-008-->
- nocap은 ID 하나라도 `@`가 없거나 ID 사이에 쉼표가 없는 주석을 테스트 태그로 인식하지 않음. 예: `// @A-001, A-002`, `// @A-001 @A-002` <!--@TP-009-->
- nocap은 문자열과 템플릿 리터럴 안의 `// @ID`를 무시함 <!--@TP-010-->

## 입력 언어와 오류
- nocap은 파일 확장자로 언어를 정함. `.ts`, `.mts`, `.cts`는 TypeScript, `.tsx`는 TSX, `.js`, `.mjs`, `.cjs`는 JavaScript, `.jsx`는 JSX로 읽음 <!--@TP-011-->
- nocap은 지원하지 않는 확장자의 파일을 오류로 보고함 <!--@TP-012-->
- nocap은 문법 오류가 있는 테스트 파일을 오류로 보고하고 그 파일로 테스트 항목을 만들지 않음 <!--@TP-013-->
