# 용어집

- 이 문서는 도메인 객체가 쓰는 용어만 정의한다.
- 도메인 객체를 만들 때 같은 커밋에서 그 용어를 추가한다.

## spec

- 명세 항목(`SpecItem`): 명세 문서에서 명세 태그로 ID를 받은 리스트 항목이다.
  - 명세 태그의 형식과 위치는 [nocap 문법](syntax.md)이 정한다.
- ID(`id`): 명세 항목을 가리키는 문자열이다. 명세 태그의 `@` 뒤에 쓴 값이다. 예: `<!--@AUTH-001-->`의 ID는 `AUTH-001`
  - 테스트 태그는 이 ID로 명세 항목을 가리킨다.

## test

- 테스트 항목(`TestItem`): 테스트 파일에서 테스트 태그가 붙은 테스트 호출이다. 예: `it()`, `describe()`
  - 테스트 태그의 형식과 위치는 [nocap 문법](syntax.md)이 정한다.
- ID 목록(`ids`): 테스트 항목이 가리키는 명세 항목의 ID들이다. 테스트 태그에 쓴 순서를 따른다. 예: `// @AUTH-001, @AUTH-002`의 ID 목록은 `AUTH-001`, `AUTH-002`

## coverage

- 커버리지(`Coverage`): 명세 항목과 테스트 항목을 ID로 연결한 판정 결과다. 명세 커버리지, 알 수 없는 ID, 중복 ID의 목록을 가진다.
  - 커버리지 비율과 다르다. 커버리지는 비율 값을 가지지 않는다.
- 명세 커버리지(`SpecCoverage`): 명세 항목 1개와 그 명세 항목에 연결된 테스트 항목 목록이다.
  - 연결된 테스트 항목이 1개 이상이면 그 명세 항목은 커버됨이다. 없으면 커버되지 않음이다.
- 알 수 없는 ID(`UnknownId`): 테스트 항목이 가리키지만 어떤 명세 항목의 ID와도 같지 않은 ID다. 그 ID를 가리키는 테스트 항목 목록을 함께 가진다. 예: 명세 항목에 없는 `AUTH-999`를 가리키는 `// @AUTH-999`
- 중복 ID(`DuplicateId`): 명세 항목 2개 이상이 같이 가진 ID다. 그 ID를 가진 명세 항목 목록을 함께 가진다.
